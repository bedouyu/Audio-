# 启动与学习路线

## 启动

1. 确保原项目的 MySQL、MinIO、Qdrant、Redis 服务可连接；它们可以是本机服务，也可以继续使用已有容器。启动脚本不会自动安装或启动 Docker。
2. 双击项目根目录 start-backend-local.cmd。它使用 JDK 17 编译 backend，并在 http://127.0.0.1:18081 启动。
3. 双击 start-frontend-local.cmd，打开 Electron + Vue 桌面窗口。
4. 登录已有账号，或注册账号。进入项目后可导入资料、问答、生成音频，或恢复之前的对话。

配置模型密钥后，新聊天默认启用多 Agent。可输入“根据本项目资料，生成一份适合初学者的 5 分钟课程讲稿，并复核内容与引用”，再到“Agent 产物”查看结果。计划和讲稿须明确确认后才应用或合成；无密钥时只运行基础检索演示。设置 AUDIORAG_AGENT_ENABLED=false 可切回旧流程。

原版本机连接默认值已迁入 backend/config/application-private.yml，文件被 .gitignore 排除。更换服务时在此文件修改 MySQL、MinIO 的连接信息。私有文件丢失时，可复制 application-private.example.yml 并填写。数据库名默认继续使用 docpilot，MinIO bucket 与 Qdrant collection 也保持原项目设置。

模型可使用已有的 DEEPSEEK_API_KEY Windows 用户环境变量，也可设置 AUDIORAG_LLM_API_KEY。不要把密钥写进 Java、提示词或公共配置。模型名称用 AUDIORAG_LLM_MODEL 指定。未设置密钥仍可根据已有知识库生成摘录式内容；仍需数据库与检索服务。

本机工具默认路径：
- JDK：D:/AI-Toolchain/jdk-17.0.20.1+1
- Node.js：D:/DevTools/nodejs
- Maven：D:/DevTools/apache-maven-3.9.16
- 向量模型：D:/AI-Toolchain/models/bge-small-zh-v1.5

IDEA 直接打开 backend/pom.xml，项目 SDK 设为 17，运行 AudioRagApplication，工作目录设为 backend。以此找到 config 私有配置和 ../tools/synthesize.ps1。

```powershell
cd "D:\desktop\AI\AI音频\audiorag-java"
.\build-all.ps1
```

构建运行后端测试与桌面测试，并生成 backend/target/audiorag-backend.jar、desktop/out。缓存放在本项目 .cache 中。旧 scripts/start-java.ps1 仍可用，它转入新的启动脚本。

## 建议阅读顺序

1. controller/ConversationController 与 model/dto：理解请求边界。
2. repository/AudioRagRepository、model/entity 与 mapper：理解存储、项目归属和 API 转换。
3. agent/audio/AudioAgent：理解问答与音频生成如何组合。
4. core/loop/AudioRetrievalLoop、tools/ToolRegistry：理解工具调用与本机/网络证据。
5. service/memory/ConversationMemory：理解滑动窗口为何按完整轮次裁剪。
6. ai/AiModelGateway、LlmGenerationService 与 prompts/audio：理解模型替换与流式返回。
7. service/ContinuousAudioService、tools/audio/SpeechService：理解后台预取与音频恢复。
8. desktop/src/main、preload、renderer：理解 Electron 权限边界和 Vue 组件拆分。

桌面组件分别为 ProjectDashboard、KnowledgePanel、AudioPanel、ChatPanel，状态与 API 封装在 useWorkspace。旧网页只供参考，位于 legacy/pwa；原版交接文档位于 legacy/HANDOVER-v1.md。
